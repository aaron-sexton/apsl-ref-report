APSL Referee Match Report – adding it to the APSL website

Form link (permanent – this link does not change when the form is updated):
  https://tinyurl.com/apsl-ref-report

Please add it in one of these two ways (option A is preferred):

A) A button or menu link
   Label:  Referee Match Report
   Link:   the form link above
   Open in a new tab.

B) Embedded on a page
   Paste this into an HTML / embed block:

   <iframe src="https://tinyurl.com/apsl-ref-report"
           title="APSL Referee Match Report"
           style="width:100%;height:90vh;min-height:700px;border:0"
           loading="lazy"></iframe>

   If your embed block adds a "sandbox" attribute, please include:
   allow-scripts allow-same-origin allow-forms allow-popups allow-downloads

If both are possible, please do both: the embedded form on the page, plus a
"Open in a new window" link under it for referees on phones.
